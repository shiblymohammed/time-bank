# Time Bank web dashboard

For frontend design and restyling in `apps/web`, use the project-local [frontend-design skill](../../.agents/skills/frontend-design/SKILL.md) and [Taste Skill](../../.agents/skills/design-taste-frontend/SKILL.md). Read [PRODUCT.md](../../PRODUCT.md) for the staff workflows and [DESIGN.md](../../DESIGN.md) for the dashboard's visual system. Use Impeccable when the task calls for documenting, reviewing, or refining the interface.

Apply the frontend-design guidance on hierarchy, layout, and copy within the existing Municipal workbench direction. Use the dashboard's existing tokens and controls in both themes. Choose a new aesthetic anchor when the brief calls for a new visual identity or explicitly requests an anchor.

Apply Taste Skill's alignment, plain-language copy, responsive checks, and interaction polish to staff screens. Use its page composition, imagery, and motion guidance for public-facing pages when the brief calls for them.

Use standard labels for familiar actions and real product information in the interface. Label sample records as samples whenever they appear in a preview.
